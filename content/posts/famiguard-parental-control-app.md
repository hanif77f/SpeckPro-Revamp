## FamiGuard and AccessibilityService API

FamiGuard uses Android's AccessibilityService API to support several of its parental-control features.

Accessibility services provide applications with the ability to interact with certain device functions in ways that help deliver enhanced functionality.

In FamiGuard's case, AccessibilityService helps support features such as:

- Monitoring applications currently in use
- Restricting selected apps
- Enforcing screen-time controls
- Supporting remote device locking
- Managing device-access rules

These features require appropriate user consent and setup before they become active.

### Why Does FamiGuard Need AccessibilityService?

Some parental-control features cannot function effectively without access to certain device-level capabilities.

For example, if a parent chooses to restrict access to a specific application, the app must be able to recognize when that application is opened in order to apply the restriction.

Similarly, screen-time controls and device-locking features require interaction with system-level functionality.

AccessibilityService provides the technical capability needed to support these parental-control functions.

### What FamiGuard Does Not Use AccessibilityService For

According to the app's stated functionality, AccessibilityService is not used for:

- Recording phone calls
- Recording audio
- Reading sensitive personal messages
- Unauthorized data collection
- Deceptive behavior
- Unauthorized system modifications
- Bypassing Android security protections

The service is activated only after user consent and is intended solely for parental-control functionality.
